## HIGH

2. The transform algebra cannot deterministically account for all certificate-to-inference fields.

`CertificateEndpoint` and `InferenceEndpoint` are different shapes. Source-only fields include notion, relation, operator, mechanism, score family, and candidate domain; target-only fields include inference guarantee, inference target, conclusion, subject, and covering certificate. The transform enum has no typed operation for several of these fields or for exclusions, yet `I-BRIDGE-TRANSFORM-01` claims the entire target is deterministically obtained from the source.

This leaves permissive implementations able to inject target conclusions or silently discard source restrictions, while strict implementations must reject all such inference bridges.

3. “Proof-bound” transforms accept an unrelated theorem Claim.

`rule_proof_claim_digest` is only required to resolve to a theorem Claim with a sufficient floor. No invariant requires that Claim’s assertion schema or conclusion bind the transform’s `rule_digest`, kind, input, output, formula, pins, or domains.

An unrelated certified theorem can therefore satisfy the structural check for a NOTION_MAP, RELATION_MAP, QUANTIFIER_MAP, or heterogeneous budget map.
