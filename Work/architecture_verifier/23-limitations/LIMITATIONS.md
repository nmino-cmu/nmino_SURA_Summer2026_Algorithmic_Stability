# 23 — Known Limitations

**Artifact ID:** `ART-23`  
**Version:** `ARCH-0.2`

1. Correlated LLM critic failures remain possible despite triggered diversity.
2. Sophisticated wrong proofs (“competence theater”) are only partially caught by process; human review remains necessary.
3. Ground-truth citation verification requires future tooling (DOI/PDF) at implementation time.
4. Deferred measure-theoretic Lean may leave inference-facing claims `PROVED_ON_PAPER` without `LEAN_FULL` for long periods — must not be marketed as machine-verified.
5. Bullshit metrics can false-positive or false-negative; fail-closed prefers blocks.
6. Legal retention vs eternal failure logs not addressed (out of research architecture scope).
7. Design package is implementation-neutral; build plan is a separate phase after `DESIGN_FINAL`.
9. ITER5: C12 resets on material ops/governance changes; prior “green C12” is not permanent.
10. Correlated LLM critics remain residual; OPERABLE_MINIMAL hard contract is design-time — enforcement needs implementation.
